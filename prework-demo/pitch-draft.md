# 30-Second Pitch Draft

## Template
```
What we built: [1 sentence]
The problem: [1 sentence - who it affects]
Our solution: [1 sentence - how it works]
Tech: [1 sentence - key tech]
Why it matters: [1 sentence - impact]
```

## Example
```
What we built: An AI-powered code review assistant that catches bugs and suggests improvements in real-time.

The problem: Developers spend 30% of their time on manual code reviews, which slows down development cycles.

Our solution: We integrated GPT-4 with semantic code analysis to automatically review pull requests, catching security vulnerabilities, performance issues, and style violations in seconds.

Tech: FastAPI backend, React frontend, OpenAI GPT-4, vector database for context.

Why it matters: Cuts code review time by 80%, helping teams ship faster without sacrificing quality.
```

## Practice Checklist
- [ ] Say it out loud 3 times
- [ ] Time it (aim for 25-30 seconds)
- [ ] Adjust for clarity
- [ ] Memorize the opening line
- [ ] Prepare for "tell me more" follow-ups

## Common Follow-up Questions
1. "How does it handle privacy/sensitive data?"
2. "What's the latency?"
3. "How much does it cost to run?"
4. "Can it integrate with [tool]?"
5. "What's the business model?"
