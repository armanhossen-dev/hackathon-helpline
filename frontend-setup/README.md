# Frontend Setup - AI Dev Hackathon

## Your Role
**Frontend Developer** (using VibeCode / AI-assisted coding)

## Team
- Person 1: [Backend/API]
- Person 2: [ML/AI Model]
- Person 3: **You - Frontend/UI**

## Quick Setup (one command)
```bash
./scripts/install.sh
```

Or manually:
```bash
npm install
pip install -r requirements-python.txt
```

## Tech Stack
- **Build**: Vite + React 18 + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Animation**: Framer Motion
- **State**: Zustand
- **Routing**: React Router v6
- **Forms**: React Hook Form + Zod
- **Icons**: Lucide React
- **AI Integration**: OpenAI SDK / Anthropic SDK
